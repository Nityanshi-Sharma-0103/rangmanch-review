# 🎭 Rangmanch Review API

A RESTful review management API built with **FastAPI** and **SQLite**.

This project allows users to create and manage reviews for plays/theatre performances. It demonstrates backend API development, database integration, request validation, CRUD operations, and interactive API documentation with Swagger UI.

---

## 🚀 Features

- Create reviews for plays
- Store reviews in a SQLite database
- Retrieve reviews
- Update existing reviews
- Delete reviews
- Rating support
- Request validation with Pydantic
- RESTful API architecture
- Interactive Swagger UI documentation
- Automatic OpenAPI documentation
- SQLite database integration

---

## 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **SQLite**
- **SQLAlchemy**
- **Pydantic**
- **Uvicorn**
- **Swagger UI / OpenAPI**
